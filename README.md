# co-surge-rules-set

A public, node-agnostic Surge 6 rule & policy set.

Rules, policy groups and general settings live here and are meant to be shared.
**Nodes never are.** Proxy definitions stay on your own machine and are pulled in
locally, so nothing in this repository contains a server address, password or
subscription link.
